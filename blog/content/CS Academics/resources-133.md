### 🚀 Linux Tools - System Monitoring Utilities

Fundamental command-line utilities for monitoring system resources in Linux environments. It explains the core functionalities of tools like pidstat and netstat for system diagnostics and performance analysis.

Key Points:

• `pidstat` tracks CPU, memory, I/O, task switching, and threads for processes.

• `netstat` displays active network connections, routing tables, and interface statistics.

• These tools are essential for identifying performance bottlenecks and troubleshooting system issues.
