### 🚀 Tech - GitHub REST API Updates

GitHub has introduced a new star history REST API endpoint that allows users to track a repository's star growth over time without exposing stargazer identities. This update provides insights into a repository's popularity without compromising user privacy.

Key Points:

- **The new star**: history REST API endpoint provides a privacy-safe way to track a repository's star growth over time.

- **Stargazer listing endpoints**: were previously restricted to admins and collaborators to protect user privacy.

- **The new endpoint**: allows users to get insights into a repository's popularity without exposing stargazer identities.
