## How to Publish
1. Create a markdown file here (e.g. `my-post-title.md`).
2. Start with a top-level heading `# Your Title`.
3. Articles placed here automatically receive:
   - Category: **Personal**
   - Slug: `/articles/personal/your-post-title`
   - Pin Priority: Pinned at the very top of the homepage and search feeds
   - Badge: **⭐ Author Note / Personal**
