## Prompt (verbatim as published)

````text
Create an extraordinary 3D audio visualizer experience driven by a full-length, catchy EDM/dubstep track titled "SINGULARITY" — with the music itself generated in code at runtime using Web Audio synthesis (kick, bass, synth leads, hats, risers, drops) and no external audio assets. The visual centerpiece is a swirling black hole in deep space whose accretion disk, gravitational lensing glow, particle streams, and surrounding starfield all pulse, warp, and detonate in sync with the music.

Structure the track like a real song — intro build, verse, riser, drop, breakdown, a second bigger drop, and an outro — and give each section its own visual chapter: camera choreography, color palette shifts, particle behavior, and intensity that follow the arrangement. The visuals must be genuinely audio-reactive, with frequency-band analysis animating motion, scale, bloom, and camera shake on the beat — never a fixed animation with music laid on top. When the drop hits, the scene should feel like it is coming apart; in the breakdown, it should breathe.

Include transport controls (play, pause, restart, and seek if feasible), a small set of visual presets, quality scaling so weaker machines keep the beat, and a minimal interface that dissolves away during playback and returns on approach. Everything must run from the portable static artifact with no network dependency: the track, the visuals, and every asset are generated or bundled locally.

Do not take shortcuts or settle for a bouncing-bar equalizer over a stock space photo. This skill imposes no token budget limit, so pursue the full depth of both halves — a genuinely listenable multi-minute track with real musical structure, and a layered, performant WebGL show that feels authored to the music — and keep refining until the whole piece plays like a self-contained music video.
````
